# TaskFlow

TaskFlow é uma aplicação simples de gerenciamento de tarefas pessoais, criada para estudo de programação e fluxo de trabalho com Git/GitHub.

O projeto usa apenas HTML, CSS e JavaScript puro. Ele não precisa de backend, banco de dados ou instalação de dependências, e pode ser publicado diretamente com GitHub Pages.

## Como clonar o repositório

```bash
git clone https://github.com/seu-usuario/taskflow.git
```

Depois, acesse a pasta do projeto:

```bash
cd taskflow
```

## Como executar localmente

Abra o arquivo `index.html` diretamente no navegador.

## Estrutura do projeto

```text
taskflow/
|-- index.html             página principal
|-- estilos/               pasta de estilos
|   `-- estilo.css         estilos da aplicação
|-- scripts/               pasta de scripts
|   `-- tarefas.js         lógica da aplicação
|-- README.md              instruções do projeto
`-- .gitignore             arquivos ignorados pelo Git
```

- `index.html`: estrutura da página da aplicação.
- `estilos/estilo.css`: estilos visuais e regras de responsividade.
- `scripts/tarefas.js`: lógica para criar, listar, editar, concluir e excluir tarefas.
- `README.md`: instruções básicas do projeto.
- `.gitignore`: arquivos e pastas que não devem ser versionados.
